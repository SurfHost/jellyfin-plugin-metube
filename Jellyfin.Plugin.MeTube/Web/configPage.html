MeTube

Search YouTube from Jellyfin and download videos with your MeTube server straight into a Jellyfin library. MeTube has no login of its own: keep it on your LAN. Only the users ticked below (and administrators) can search and add.

MeTube server

As reachable from the Jellyfin server, on the LAN.
Folder inside MeTube's download directory that is mounted as the Jellyfin library, e.g. youtube.
Name of MeTube's TEMP_DIR inside that folder, e.g. .metube-tmp. Empty folders left there are removed while MeTube is idle. Leave empty to switch this off.
Comma-separated YTDL_OPTIONS_PRESETS names applied to every download, e.g. jellyfin.

Jellyfin library

Used to spot videos that are already there, to scan new downloads right away, and to open them with Play.

Who may add videos

Limits apply to non-admin users. Live streams and premieres can never be added.

Menu entry and search

Adds YouTube to the side menu and header for allowed users. Untick if a Jellyfin update ever breaks the page; "Open YouTube search" above keeps working.
